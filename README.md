# Fable | VPN — Telegram-бот для продажи VPN

Python 3.12 · aiogram 3 · PostgreSQL · Redis · Remnawave 3.x · ЮKassa · Docker Compose

**Запуск:** см. [`docs/SETUP.md`](docs/SETUP.md) — что подключить и как.

## Что умеет

**Пользователь** (кнопки строго по ТЗ):
`Подключиться` → главное меню (`Моя подписка` · `Реферальная система` · `Поддержка`) → оплата/продление, тарифы LITE и PREMIUM,
настройка (Happ: скачать / добавить подписку — ссылки сами определяют ОС), список устройств (удалить / переименовать / добавить),
рефералка и промокоды.

**Правила подписок**
* Пробный период — 7 дней PREMIUM.
* LITE → PREMIUM: доплата пропорционально остатку + новый период (пример: 15 дней LITE → 50 ₽ + 249 ₽ = 299 ₽, итого 45 дней PREMIUM) — либо дождаться конца LITE.
* PREMIUM → LITE: LITE встаёт в очередь и включается после окончания PREMIUM; при переходе лишние устройства отключаются (самые новые).
* Приглашённый подключился и пользуется VPN → пригласивший получает +7 дней LITE.
* Промокоды: скидка (% или ₽) либо бонусные дни LITE/PREMIUM.
* Лимиты по тарифам: LITE — 3 устройства / 5 локаций; PREMIUM — 5 устройств / 10 локаций + белые списки (задаётся сквадами Remnawave).

**Админка** (`/admin`, всё без консоли): статистика и графики, пользователи (поиск, карточка, начислить/снять дни, тариф и срок,
устройства, бан, заметки, сообщение, новая ссылка, удаление), платежи (проверка, возвраты), тарифы (цены, лимиты, сквады из панели),
промокоды (мастер создания), рефералка, рассылки (любой контент, сегменты, пауза), редактор всех текстов бота,
панель VPN (ноды: включить/отключить/перезапустить, сквады), настройки, админы, диагностика, бэкап БД, журнал ошибок и действий.

**Надёжность:** блокировки на пользователя, идемпотентная обработка платежей, сверка платежей по API (не верим вебхуку на слово),
повтор синхронизации с панелью при сбоях, воркеры (истечение, напоминания, награды), ежедневный бэкап в Telegram.

## Структура

```
app/
  core/          чистая логика подписок и цен (без БД/сети; покрыта тестами)
  db/            модели SQLAlchemy 2.0
  integrations/  клиенты Remnawave 3.x и ЮKassa v3 (httpx)
  services/      бизнес-логика: подписки, платежи, промокоды, рефералы, рассылки, статистика…
  bot/           aiogram: middlewares, экраны (views), хендлеры user/ и admin/
  web/           aiohttp: вебхуки ЮKassa/Remnawave, страницы /dl и /add для Happ
  workers/       фоновые задачи
tests/           юнит-тесты логики
scripts/check_code.py   статическая проверка (имена, импорты, кнопки↔обработчики, тексты)
```

## Разработка

```bash
python -m unittest discover -s tests -v     # тесты логики подписок, цен и текстов
python scripts/check_code.py                # статическая проверка проекта
```

Новые тексты добавляются в `app/texts.py` — они сразу становятся редактируемыми из админки.
